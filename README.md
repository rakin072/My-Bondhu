## Getting started

> **Prerequisites:**
> The following steps require [NodeJS](https://nodejs.org/en/) to be installed on your system, so please
> install it beforehand if you haven't already.

To get started with your project, you'll first need to install the dependencies with:

```
npm install
```

Then, you'll be able to run a development version of the project with:

```
npm run dev
```

After a few seconds, your project should be accessible at the address
[http://localhost:5173/](http://localhost:5173/)


If you are satisfied with the result, you can finally build the project for release with:

```
npm run build
```

## Frontend + Node.js Backend

This project now uses a split structure:

- Frontend: Vite + React at the repository root
- Backend: Node.js + Express in [server](server)

The frontend still keeps local browser state for app features. The backend is ready for your new endpoints under `/api`.

### Install dependencies

From the project root:

```bash
npm install
npm --prefix server install
```

### Run both frontend and backend (development)

```bash
npm run dev
```

- Frontend: [http://127.0.0.1:5173](http://127.0.0.1:5173)
- Backend: [http://127.0.0.1:3001/api/health](http://127.0.0.1:3001/api/health)

Vite proxies `/api/*` to `http://127.0.0.1:3001` during development.

### Run app with free public tunnel

Use one command to start the app and the temporary Cloudflare URL together:

```bash
npm run dev:tunnel
```

This launches:

- frontend on `http://localhost:5173`
- backend on `http://localhost:3001`
- a free temporary `trycloudflare.com` URL for the frontend

Because Vite proxies `/api/*` to the backend, the public tunnel only needs to expose the frontend port.

### Run backend only

```bash
npm run start:server
```

### Backend environment

Copy [server/.env.example](server/.env.example) to `server/.env` and adjust values if needed.

### Cloudflare Quick Tunnel

This project can be shared publicly without buying or configuring a domain by using Cloudflare Quick Tunnel.

Run the app and tunnel together:

```bash
npm run dev:tunnel
```

Cloudflare will print a temporary `trycloudflare.com` URL. Use that URL in your browser or Telegram WebApp for testing.

Notes:

- The URL changes each time you restart the tunnel.
- This is ideal for development, testing, and sharing a demo.
- For production, a permanent hostname still needs Cloudflare DNS or another domain setup.

### Netlify redirects

Netlify is configured with an SPA fallback redirect to `index.html` so client-side routing works in production.
