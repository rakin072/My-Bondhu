## Getting started

> **Prerequisites:**
> The following steps require [NodeJS](https://nodejs.org/en/) to be installed on your system, so please
> install it beforehand if you haven't already.

To get started with your project, you'll first need to install the dependencies with:

```
npm install
```

Then, you'll be able to run a development version of the project with:

```
npm run dev
```

After a few seconds, your project should be accessible at the address
[http://localhost:5173/](http://localhost:5173/)


If you are satisfied with the result, you can finally build the project for release with:

```
npm run build
```

## Backend (Node.js + SQLite)

This project now includes a Node.js backend with SQLite at [server/index.js](server/index.js).

### Run backend API

In a second terminal, run:

```
npm run dev:server
```

The API runs at [http://127.0.0.1:3001](http://127.0.0.1:3001), and the SQLite database file is created at [server/data/mybondhu.db](server/data/mybondhu.db).

### API routes

- `GET /api/health`
- `POST /api/auth/telegram`
- `GET /api/users/:telegramId`
- `POST /api/mining/claim`
- `GET /api/mining/history/:telegramId`

Frontend `/api/*` calls are proxied by Vite to the backend in dev mode.
